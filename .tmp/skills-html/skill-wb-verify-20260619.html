wb-verify · 远端验证与测试门禁

Workbench Skill ID wb-verify · 源文件 yuanrong-datasystem-agent-workbench/.cursor/skills/wb-verify/ · TDD 5/5 contract tests · 2026-06-19

在 tiantiyun 跑 smoke/UT/ST 及 KV executor、URMA 日志等专项门禁。

何时使用

改代码后声称「已验证」、合入前跑 harness、匹配 verify_matrix 最低级别。

典型触发语：跑 smoke、远端验证、validate_kv_executor、URMA 日志校验

默认节点/环境：tiantiyun-80c128g

命令与脚本

用途命令
Smokebash scripts/testing/verify/smoke/run_smoke_remote.sh
UTbash scripts/testing/verify/ut/run_ut_remote.sh
STbash scripts/testing/verify/st/run_st_remote.sh
KV executorbash scripts/testing/verify/validate_kv_executor.sh --skip-build
URMA/TCP 日志bash scripts/testing/verify/validate_urma_tcp_observability_logs.sh

工作流

  1. rsync/build datasystem 到 tiantiyun（如需）
  2. 按 verify_matrix.yaml 选 minimum 级别
  3. 记录命令、节点、退出码与产物路径
  4. xqyun 仅用于 sync/HTML，非默认 verify 节点
